How to Make Dynamic Broadcast Lower Thirds

2026-08-16

Lower Thirds are graphics that display additional information to supplement video storytelling or sometimes ultimately explaining to audiences what they are even looking at. They provide a title safe and lower area of the screen form of communication. You will see them being used all of the time on the news or on your grandmothers favorite game show.
But have you ever wondered how they create these lower thirds that are adaptable to font size and positioning of text? It appears that even if it is a full paragraph of information, it stills fit in the box perfectly. Early in my creative years I often used Lower Third MOGRTs from Adobe Stock, but it would always be a limitation to how many characters I could use or the amount of information I could lay out. Here's a guide to how I create dynamic lower third MOGRTs for preproduced segments and even live segments.

  1. Open a project with your lower third graphic.
  2. Add 3 Slider Control effects to your text layer\(Make sure your text layer isn't a text box. This causes sizing issues later.)\
  3. Name each box as follows: Max Characters Per Line, Absolute Max Characters and Font Size.
  4. Navigate to source text to your text layer and alt-click on the stopwatch icon to activate expressions.
  5. Enter this value into the expression:

*\\\\Referencing your controllers\\\\***
var maxChars = effect("Max Characters Per Line")("Slider");
var absoluteMaxTotal = effect("Absolute Max Characters")("Slider");
var targetFontSize = effect("Font Size")("Slider");

var txt = value.substring(0, absoluteMaxTotal);
var words = txt.split(" ");
var currentLine = "";
var finalResult = "";
for (var i = 0; i < words.length; i++) {

if ((currentLine + words[i]).length > maxChars) {
finalResult += currentLine.trim() + "\\n";
currentLine = words[i] + " ";
} else {
currentLine += words[i] + " ";
}
}
finalResult += currentLine.trim();
var proportionalLeading = targetFontSize \* 1.2;

style.setText(finalResult)
.setFontSize(targetFontSize)
.setLeading(proportionalLeading);

Now you should be able to use the slider controls to control the max characters per line, how many characters to fit in the base of your graphic and font size.

6\. Navigate to transform and then position\. Alt-click on the stopwatch to activate expressions again.
7\. Enter these values into the expression:
var subTextLayer = thisComp.layer("Sub-text Layer Name Here");

Make sure the sub-text layer's name is in the placeholder spot and exactly what the name of the layer is.

var subTextString = subTextLayer.text.sourceText.value.toString().trim();
var shiftAmount = 30;

The "shiftAmount" value will determine the amount of pixels the top layer text shifts.

var currentPos = value;
if (subTextString.length > 0 && subTextString !== "") {
[currentPos[0], currentPos[1] - shiftAmount];
} else {
currentPos;
}

This calculates the direction of where the top layer text goes to.

Now you should have a fully functional standard Broadcast lower third, that has dynamic functionality. Granting the ability to control the length, size and amount of characters on lower thirds.
